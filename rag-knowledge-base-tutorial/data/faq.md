# 智能云盘常见问题（FAQ）

## 账号与计费

**Q：可以随时升级或降级版本吗？**
A：可以。升级立即生效，按剩余天数补差价；降级在当前计费周期结束后生效，降级后超出存储上限的文件会转为只读，不会被删除。

**Q：成员离职后，他上传的文件会删除吗？**
A：不会。文件归属于团队空间，与成员账号解绑。管理员可以在成员管理中移除账号，并选择是否回收其个人空间的文件。

**Q：如何申请发票？**
A：在"企业设置 - 账单"中可申请增值税普通发票或专用发票，团队版支持按月开票，企业版支持按合同约定开票。

## 使用问题

**Q：误删了文件怎么办？**
A：文件先进入回收站，保留 30 天，可一键恢复；若开启了版本历史，也可以从任意历史版本恢复。

**Q：同步冲突怎么处理？**
A：同一文件在多台设备同时修改时，客户端会生成冲突副本（文件名带"冲突"标记与设备名），请手动合并后删除多余的副本。

**Q：支持断网使用吗？**
A：桌面客户端支持"本地暂存"模式，断网期间的修改会在网络恢复后自动同步。

## API 与集成

**Q：提供 API 吗？**
A：提供 RESTful API 与 Webhook，团队版每日调用上限 1 万次，企业版不限。开放平台文档位于 developer.example.com/cloud-drive。

**Q：能否对接企业微信 / 飞书 / 钉钉？**
A：支持。可在"企业设置 - 应用集成"中一键授权绑定，实现消息通知与免登跳转。
